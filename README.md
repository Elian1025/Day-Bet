# Day-Bet
Algo para esa personita

## Fotos

En las pantallas de inicio y del puzzle, pulsa **Cambiar foto** para elegir una imagen distinta. Las fotos se guardan en IndexedDB y se recuperan al volver a abrir el proyecto en el mismo navegador y origen. Usa JPG, PNG, WebP o AVIF de hasta 20 MB y 24 megapíxeles. La ilustración de la sorpresa final es fija.

Las fotos no se suben a un servidor ni se comparten entre dispositivos. Para conservarlas en otro navegador, vuelve a seleccionarlas allí.
